# Дистилляция знаний для компактного классификатора

В эксперименте сравниваются две сети 2 → 6 → 4 с одинаковой инициализацией внутри каждой пары. Baseline учится по меткам, distilled student — по меткам и мягким целям teacher. Teacher имеет архитектуру 2 → 48 → 4.

## Интерфейс в браузере

Откройте `ui.html` двойным щелчком. Интернет, сервер и установка пакетов не нужны. Выберите seed и нажмите «Запустить обучение», чтобы переобучить обе student-модели. Флажок «Обучить teacher с нуля» добавляет обучение teacher перед запуском student.

На графике можно переключать потери и точность на валидации. Щелчок на любой карте выбирает одну и ту же точку для трёх моделей. Кнопки «Где помогла» и «Где помешала» показывают тестовые примеры, на которых правильной оказалась только одна student-модель.

## Запуск

Проверено на Node.js v22.23.4. Внешние пакеты и GPU не требуются. Из папки проекта:

```powershell
node experiment.mjs
```

Можно передать путь для результатов, чтобы сохранить исходный прогон:

```powershell
node experiment.mjs results-repeat
```

В Colab эксперименту достаточно CPU-рантайма. Если в нём доступен Node.js, загрузите `experiment.mjs` и выполните `!node experiment.mjs` в ячейке. T4 для этой конфигурации не требуется.

## Выходные файлы

- `results/metrics.json` — accuracy и кросс-энтропия на validation по эпохам, итоговые метрики на test, время обучения и расчёта мягких целей.
- `results/checkpoints.json` — веса teacher и обеих student-моделей для каждой пары seed. В матрицах `first` и `last` первый столбец — bias.
- `experiment.mjs` — генерация данных, прямой и обратный проход, SGD, обучение и оценка.

Качество измеряется на общем тесте из 4096 примеров. Пять seed задают пять инициализаций и порядков батчей student. Данные и teacher общие. Измерения времени зависят от машины.

Метод: [Hinton, Vinyals, Dean, Distilling the Knowledge in a Neural Network](https://arxiv.org/abs/1503.02531).
